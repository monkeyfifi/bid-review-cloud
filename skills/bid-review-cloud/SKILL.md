# 投标文件审核 Skill (bid-review-cloud)

你被赋予了一个**投标文件 / 标书审核**任务。本 skill 包含完成审核所需的全部工具、判词库、流程指引和报告模板。

> 完整工作流与判词库见同目录 `README.md`；本文件为精简执行指引，二者互补。

## 文件结构

```
bid-review-cloud/
├── SKILL.md               ← 本文件：触发说明 + 精简执行指引
├── README.md              ← 完整工作流 + 判词库 + 评分模型
├── data/
│   └── keywords.json      ← 678条判决词（废标信号扫描用）
├── scripts/
│   ├── extract_text.py    ← PDF/DOCX 文本提取（Windows 原生，无需 poppler）
│   ├── scan_keywords.py   ← 废标信号扫描
│   ├── checker.py         ← 暗标格式检查（技术标 DOCX 用）
│   └── requirements.txt   ← pip 依赖：pypdf / python-docx / lxml
├── templates/
│   └── 审核报告模板.md     ← 标准报告模板（六章结构）
└── references/
    └── 专家判词库.md       ← 15项废标清单 + 商务清单 + 评分公式
```

## 运行环境准备

脚本依赖第三方库，使用前需安装（建议在隔离 venv 中安装，避免污染系统环境）：

```bash
pip install -r scripts/requirements.txt
```

提取与扫描脚本接受文件路径参数；`checker.py` 额外支持 `--out` 输出 JSON 与 `--rules` 自定义规则。

## 标准工作流（严格按顺序执行）

### 第一步：取数（提取文本）
从 PDF/DOCX 提取带行号的文本，作为后续分析依据。

```bash
python scripts/extract_text.py "招标文件.pdf" --outdir .
python scripts/extract_text.py "投标文件.pdf" --outdir .
```

产出：`招标文件.lines.txt`、`投标文件.lines.txt`（以及 docx 的 `*.tables.json`）。

### 第二步：撒网（扫描废标信号）
用判决词库扫描招标文件，标出关键条款位置。

```bash
python scripts/scan_keywords.py 招标文件.lines.txt --keywords data/keywords.json
```

产出：`招标文件.hits.json`，标注 primary/contract/secondary/customization/certifications/emphasis_marks 六类信号。

### 第三步：通读招标文件
逐项提取：项目基本信息、废标情形（重点"无效投标"条款）、加★实质性条款、资格要求、技术参数、商务条款、暗标格式要求、评分标准。

### 第四步：通读投标文件 — 逐项比对
按三维度逐条检查，每条说明必须包含**招标原文出处 + 投标原文出处 + 具体判定理由**：

- **A. 废标项核查（15项）**：报价超预算 / 有效期不足 / 签章不完整 / 资格不满足 / ★条款未响应 / 暗标不合规 / 信用不良 / 联合体不合规 / 分包不合规 / 附加条件 / 未按时提交 / 解密失败 / 报价偏低 / 节能产品缺失 / 无实质响应。
- **B. 商务条款响应（8项）**：★报价 / 实施时间 / 地点 / ★付款 / 验收 / ★质保期 / ★故障响应 / 同类业绩。标签：✅ 符合 / ⭐ 优于 / ⚠️ 需确认 / ❌ 不合格。
- **C. 技术参数响应**：逐条对比技术指标，每条标注状态并写明依据。

### 第五步：暗标格式检查（如有技术标 DOCX）
若用户提供技术标 DOCX，执行：

```bash
python scripts/checker.py "技术标.docx" --out 技术标.check.json
```

检查项：A4 纸张、黑色图表、宋体四号常规字、无加粗/倾斜/下划线、页边距上2.5cm 其余2cm、行距30磅固定值、无目录/封面/页眉页脚页码、无身份信息（手机号/邮箱/身份证/供应商身份词）。结果写入报告第四部分。

### 第六步：生成审核报告
按 `templates/审核报告模板.md` 的六章结构输出 MD 文件：

1. 项目信息表
2. 废标项检查（表格 + 每条写明招标原文与投标原文）
3. 商务条款响应（表格 + 标注优于项）
4. 技术参数比对（表格 + 逐条状态）
5. 暗标格式检查（如有技术标）
6. 评分预估（报价 + 商务 + 技术 = 总分）
7. 综合结论（至少 200 字，含高风险关注点与具体建议）

文件名：`审核报告_YYYYMMDD_v1.0.md`

## 评分模型（用于第六步预估）

- **报价分（25分）** = (评标基准价 / 投标人报价) × 25；评标基准价为所有有效投标最低价。
- **商务分（20分）**：同类业绩 5 分（每份 1 分，上限 5）、售后服务 8 分（低于要求一项减 4）、商务标响应 7 分（缺一项扣 2）。
- **技术分（55分）**：服务内容及指标 33 分、校区互联光纤 12 分（每减 2 对扣 4）、实施方案 10 分（10/7/4/0 四档）。

## 输出要求

- 每条比对必须写明招标原文与投标原文两端。
- 评分写具体数值与计算过程。
- 结论至少 200 字。
- 状态标记：✅ pass / ⭐ better / ⚠️ warn / ❌ fail。
