# 专家判词库 — AI比对嵌入使用

嵌入方式：在AI分析prompt中追加完整的判词库内容，让DeepSeek等模型知道"具体查什么"而非仅"查一下"。

输出格式示例（prompt中写具体值，AI会模仿）：
```
示例：
| 废标条款 | 状态 | 说明 | 出处 |
|---------|------|------|------|
| 投标报价超过预算 | ✅ 通过 | 报价638,460元，预算64万，低于1,540元 | 第三部分*1 |
| 投标有效期不足 | ⚠️ 需确认 | 招标要求60天，投标函写"在投标截止日起的有效期内"未写具体天数 | 前附表第11条 |
```

## 15项废标清单

### 1. 报价超过预算
- 招标规定：投标报价超过预算的为无效投标
- 检查方法：开标一览表报价 > 预算金额 → ❌
- 出处：前附表/第三部分加*1

### 2. 投标有效期不足
- 招标规定：前附表规定60个日历日，有效期短于此规定的投标将被拒绝
- 检查方法：投标函中明确写"自投标截止之日起XX个日历日" → 天数≥60 → ✅
- 常见陷阱：仅写"在有效期内"或"按招标文件规定" → ⚠️ 风险
- 出处：第二部分第11条、前附表第11条

### 3. 签章不完整
- 招标规定：封面须投标人全称+加盖公章；投标函须公章+签字
- 检查方法：逐页检查公章（不得用"专用章"）和签字
- 出处：第二部分12.2/12.3

### 4. 资格要求不满足
- 招标规定：须附营业执照、财务审计/承诺、纳税记录/承诺、社保记录/承诺、无违法记录声明、特定资质证明
- 检查方法：所有扫描件+加盖公章
- 出处：第三部分(二)

### 5. *条款未明确响应
- 招标规定：加*项目为必须做出明确响应的条款，否则作无效投标处理
- 检查方法：逐条对照，每条*项目在投标文件中能找到对应响应
- 出处：前附表第3条

### 6. 暗标不合规
- 招标规定：技术标中不能出现投标人名称、标识、人员名称等可识别信息
- 检查方法：word-format-checker扫描DOCX + 人工翻阅
- 出处：前附表第4条(5)

### 7. 信用记录不良
- 检查方法：信用中国、中国政府采购网、中国执行信息公开网无不良记录
- 出处：第二部分19.4(10)

## 商务条款8项通用清单

| 序号 | 条款 | 检查要点 |
|-----|------|---------|
| 1 | ★投标报价 | ≤ 预算，含完成采购项目的所有费用 |
| 2 | 实施/完工时间 | 1年（12个月） |
| 3 | 项目实施地点 | 采购人指定地点 |
| 4 | ★付款方式 | 合同签订后，线路开通后三个月内支付 |
| 5 | 项目验收要求 | 交付后由采购人组织验收 |
| 6 | ★免费质保期 | ≥ 1年（12个月） |
| 7 | ★故障响应/修复 | 响应≤30分钟，排除≤1小时 |
| 8 | 同类业绩数量 | 自规定时间以来的同类项目合同 |

## 评分计算公式

### 报价分 = (评标基准价 / 投标人报价) × 25
- 评标基准价 = 所有有效投标最低价
- 若投标人为最低价，报价分 = 25分（满分）

### 商务分（最高20分）
- 同类业绩：5分（1份/1分，上限5分）
- 售后服务：8分（低于要求一项减4分）
- 商务标响应：7分（缺一项扣2分）

### 技术分（最高55分）
- 服务内容及指标：33分（带宽7分+时延3分+路由3分+国内3分+国际3分+IP6分+裸光纤8分）
- 校区互联光纤：12分（≥24对得12分，每减2对扣4分）
- 实施方案：10分（10分/7分/4分/0分四档）
